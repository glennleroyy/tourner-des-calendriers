Instructions

1. Cliquez sur une maison pour changer son statut
2. Bouton "Ajouter une maison" : place directement un point à votre position GPS
3. Bouton "Ma position" : vous localise sur la carte
4. Bouton "Suivre" : suit votre déplacement
5. Classement : 10pts acheté, 5pts absent, 1pt non acheté, 0pt non passé
6. Statistiques : voir tous les paiements
7. Immeuble : dans la fiche d'un point, choisissez "Immeuble" pour enregistrer plusieurs achats à la même adresse
8. Administration : réservée à l'administrateur
